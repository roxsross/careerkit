# Contribuir 💜

Bienvenidas issues, propuestas, traducciones y pruebas con información ficticia.

1. Crea una rama desde `main`.
2. Editá la copia canónica bajo `skills/careerkit/`.
3. Ejecutá `python3 tests/sync_skill.py` y `python3 tests/validate.py`.
4. Incluí ejemplos que no expongan datos personales, empleadores ni credenciales.
5. Abrí un PR explicando el problema y cómo lo probaste.

No copies contenido de repositorios externos sin revisar licencias y atribuciones. En este proyecto el workflow de navegador se redactó de forma independiente.
