# 💬 CareerKit — ejemplos de uso reales

Copiá el que más se parezca a tu situación y cambiá los datos entre corchetes. **No incluyas datos privados de otras personas o empresas.**

## 1. Mi primer LinkedIn IT

```text
Usá careerkit. Estoy estudiando desarrollo web y todavía no tuve mi primer empleo IT.
Mis proyectos son: [proyectos]. Estas tecnologías usé: [stack].
Auditá mi LinkedIn, sugerime 3 headlines, un About y 5 proyectos para destacar.
No me atribuyas experiencia profesional que no tengo.
```

## 2. DevOps con experiencia que quiere crecer

```text
Usá careerkit para posicionarme como Platform Engineer.
Mi experiencia real: [pegá responsabilidades, mejoras y resultados].
Quiero una auditoría de 10 segundos, keywords, 3 titulares y un About natural.
Separá resultados demostrables de métricas pendientes de validar.
```

## 3. Despido o transición laboral

```text
Usá careerkit. Me desvincularon y necesito organizar la búsqueda sin agotarme.
Trabajo en [área], tengo [años] y estoy en [mercado/país].
Creá un plan realista de 5 días con CV, LinkedIn, contactos y entrevistas.
No prometas conseguir trabajo. Priorizá lo urgente.
```

## 4. Foto de perfil Tech Leader

```text
Usá careerkit para un prompt de retrato Tech Leader.
Voy a usar una foto de referencia propia. Quiero una luz natural, fondo urbano
moderno y ropa casual profesional. Preservá mi rostro, edad aparente,
textura de piel y expresión. Dame un prompt y errores que debo evitar.
```

## 5. Foto profesional, tres opciones

```text
Usá careerkit para comparar 3 estilos para mi foto de LinkedIn:
corporativo, minimalista y académico. Trabajo en [industria].
Recomendá uno, explicá por qué y escribí el prompt en español.
No cambies mis rasgos ni generes una foto si no hay herramienta de imagen.
```

## 6. Mensaje para recruiter

```text
Usá careerkit. Un recruiter me escribió por un puesto de [rol].
Mi experiencia relevante: [3 datos reales].
Redactá una respuesta breve, cálida y profesional, sin sonar desesperado/a.
Quiero pedir detalles sobre responsabilidades, equipo y modalidad.
```

## 7. Oportunidades internacionales

```text
Usá careerkit. Quiero adaptar mi LinkedIn a búsquedas en inglés para [rol].
Este es mi About en español: [texto].
Reescribilo en inglés natural, sin cambiar hechos ni inflar seniority.
Señalá cualquier afirmación que necesite validación.
```

## 8. De herramientas a impacto

```text
Usá careerkit para mejorar estas viñetas de experiencia: [texto].
Separá tarea, problema y resultado. No inventes porcentajes.
Dejá marcadores [POR VALIDAR] donde faltan datos concretos.
```

## 9. Preparación para entrevistas

```text
Usá careerkit para organizar 5 historias reales tipo STAR de mis proyectos:
[resumen de situaciones]. Identificá datos faltantes y sugerí preguntas
que un entrevistador técnico podría hacerme.
```

## 10. Auditoría sin acceso al enlace

```text
Usá careerkit con este LinkedIn: [URL].
Si no podés acceder al contenido, decilo y pedime el texto relevante.
No evalúes secciones que no hayas podido ver.
```
