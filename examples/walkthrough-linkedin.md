# Caso de ejemplo: de una lista de herramientas a una historia clara

> Caso **ficticio**, solo para mostrar cómo usar el skill. No representa una persona ni resultados reales.

## Entrada

```text
Usá careerkit para mejorar mi LinkedIn.
Soy Analista de Infraestructura con 3 años de experiencia.
Trabajé con Linux, AWS y GitLab CI.
Armé pipelines de CI/CD, atendí incidentes y ayudé a documentar despliegues.
Quiero buscar roles de DevOps Engineer junior/intermedio.
```

## Fragmento de respuesta esperada

**Scan de 10 segundos:** Se identifican herramientas, pero no queda claro qué procesos automatizaste, con quién colaboraste ni qué resultados podés demostrar.

**Headline 1:** `Infrastructure Analyst | Linux · AWS · GitLab CI/CD | Growing into DevOps Engineering`

**Headline 2:** `Infrastructure & Automation | CI/CD, Linux, AWS | DevOps Engineer`

**Experiencia — borrador verificable:**

- Configuré y mantuve pipelines de CI/CD usando GitLab CI para apoyar procesos de integración y despliegue.
- Participé en la atención de incidentes de infraestructura y en la elaboración de documentación operativa.
- Colaboré en iniciativas relacionadas con servicios sobre AWS y administración de sistemas Linux.

**Preguntas para mejorar el resultado:** ¿Cuántos proyectos usaban los pipelines? ¿Cuáles eran tus responsabilidades directas? ¿Tenés algún antes/después documentado?

**No hacer:** afirmar que redujiste tiempos un 70 %, lideraste un equipo o diseñaste una plataforma si esos datos no aparecen en tu experiencia.

## Cómo evaluar al agente

1. ¿Evita inventar cifras y ascensos?
2. ¿Entrega texto usable y específico?
3. ¿Identifica qué le falta para mejorar el diagnóstico?
4. ¿Se adapta al nivel profesional real?
