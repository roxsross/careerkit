# Workflow: LinkedIn profile audit

## Inputs
Use actual profile sections, role history, target roles, market/country, language, and any quantified outcomes. If the user supplies only a URL and it cannot be accessed, state the limitation and request profile text/PDF; still provide a targeted checklist if helpful.

## Sequence
1. **10-second scan:** Can a recruiter identify job family, seniority, specialization, and contribution immediately? Report strong signals, weak signals and missing evidence. Never pretend a scan was performed on unavailable content.
2. **Evidence matrix:** For each noteworthy claim record `claim | source | status: confirmed / needs verification | suggested wording`. Do not invent numbers. Treat titles like Head/Manager as aspirations unless people-management evidence is provided.
3. **Positioning:** Choose one primary job family and up to two adjacent families, plus target markets and a realistic keyword cluster. Differentiate job-fit from aspirational growth.
4. **Rewrite:** Produce three distinctly positioned headlines; a natural About; role-by-role experience bullets using action → scope → outcome when substantiated; 15–20 prioritized skills; Featured recommendations.
5. **Conversion:** Offer inbound and outbound recruiter messages and one thought-leadership post if requested. Avoid implying that posts or keywords guarantee offers.
6. **Execution:** Prioritize changes in a seven-day checklist, including ways to track *observed* outcomes without overclaiming causation.

## Output contract
- `Summary` (what works / what blocks clarity)
- `Audit` (observed vs unavailable)
- `Positioning and role fit`
- `Ready-to-paste copy`
- `Missing facts to validate`
- `Seven-day action plan` (if requested)

Use `templates/linkedin-output.md` as a skeleton. Prefer concise, concrete copy and a clear CTA. Preserve existing jobs and dates unless the user explicitly changes them.
